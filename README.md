# 🧮 스마트 계산기 (Arcade Secret Door)

완전하게 작동하는 스마트 계산기 앱이자, 시크릿 비밀번호 입력을 통해 6종의 레트로 아케이드 게임으로 진입하는 올인원 안드로이드 앱 프로젝트입니다.

---

## 🔒 시크릿 진입 & 비밀번호 설정

1. **게임 진입**:
   - 계산기 화면에서 **4자리 비밀번호(초기 기본값: `0000`)** 입력 후 **`=` 버튼**을 누르면 아케이드 게임 화면으로 전환됩니다.
   - 아케이드 게임 홈 화면 상단의 **`[🔒 나가기]`** 버튼을 누르면 다시 계산기로 복귀하며 잠깁니다.
2. **비밀번호 변경**:
   - 계산기 좌측 상단 **⚙️ 설정** ➔ **[💬 피드백 보내기]** 메뉴 선택
   - 3단계 검증 프로세스:
     1. 기존 비밀번호 입력
     2. 새 비밀번호 입력 (기존 번호와 동일 불가)
     3. 새 비밀번호 재입력 (확인)
3. **설정 메뉴 구성**:
   - 📱 **앱 정보**: 앱 버전(v1.0.0), 설명, 개발자 이메일(`opal111024@naver.com`)
   - 💬 **피드백 보내기**: 비밀번호 변경
   - 🙏 **감사의 말**: 감사 메시지
   - 💎 **프리미엄으로 업데이트**: `💸💸💸` 이스터에그

---

## 🕹️ 포함된 6종 아케이드 게임

1. 🐍 **스네이크 게임**: 체커보드 그리드 확대, 십자 방향키(`UP`, `LEFT`, `DOWN`, `RIGHT`) 및 스와이프 조작
2. 🧱 **테트리스**: 10×20 매트릭스, 점수/레벨/다음 블록 프리뷰, 원형 터치 컨트롤
3. 💥 **블록 블라스트**: 8×8 그리드, 하단 3개 블록 트레이(자동 리필 보장), 드래그 앤 드롭, 동시 라인 클리어 점수(1줄 100점 / 2줄 250점 / 3줄 350점)
4. 🚀 **벽돌 깨기 게임**: 대폭 확장된 세로 캔버스, 패들 반사 각도 물리, `< left` / `> right` 및 터치 조작
5. 🦖 **크롬 공룡 게임**: 가로 와이드 뷰, **시작 후 4초간 무장애물 보장**, 초반 저속 시작 후 점진적 가속
6. 💣 **지뢰 찾기 게임**: 캔버스 확대, **시작 전 1/2/3단계 난이도 선택 팝업**(8×8 10개 / 10×10 18개 / 12×12 30개), 320ms 롱프레스 깃발 🚩 조작

## 📲 APK 다운로드 방법 (GitHub Actions 자동 빌드)

1. **[kang-yewon/APK_game_build](https://github.com/kang-yewon/APK_game_build)** 저장소로 이동합니다.
2. 상단 메뉴의 **[Actions]** 탭을 클릭합니다.
3. 가장 최근의 **"Build Android APK"** 워크플로우를 클릭합니다.
4. 빌드 완료 후 페이지 하단의 **Artifacts** 영역에서 **`Arcade-Games-Debug-APK`**를 다운로드하여 압축을 풀면 `app-debug.apk` 파일이 있습니다.
5. 해당 APK를 안드로이드 폰에 설치하여 실행합니다.

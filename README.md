# 🎮 Arcade Fun - 6 Classic Retro Games in One APK

6가지 인기 고전/아케이드 게임이 하나로 통합된 안드로이드 게임 앱 프로젝트입니다.

---

## 🕹️ 포함된 게임 목록

1. 🐍 **스네이크 게임 (Snake Game)**
   - 체커보드 그리드, 사과 먹기, 픽셀 뱀 조작
   - 십자 방향키(`UP`, `LEFT`, `DOWN`, `RIGHT`) 및 스와이프 제스처 지원
2. 🧱 **테트리스 (Tetris)**
   - 10×20 공식 규격 매트릭스, 라인 클리어 콤보
   - 점수, 레벨, 다음 블록(Next) 프리뷰, 원형 터치 컨트롤(`왼쪽`, `회전`, `오른쪽`, `낙하`)
3. 💥 **블록 블라스트 (Block Blast)**
   - 8×8 그리드 및 하단 3개 블록 트레이
   - 터치 드래그 앤 드롭 배치 (손가락 시야 가림 방지 오프셋 적용)
   - 가로/세로 동시 폭파 및 연쇄 콤보 시스템
4. 🚀 **벽돌 깨기 게임 (Brick Breaker)**
   - 우주 테마 배경 및 다채로운 벽돌 레이어
   - 하단 패들 반사 각도 물리 연산, `< left` / `> right` 버튼 및 패들 터치 드래그
5. 🦖 **크롬 공룡 게임 (Chrome Dino Runner)**
   - 가로(Landscape) 와이드 뷰포트 레이아웃
   - 달리는 T-Rex 공룡, 선인장/익룡 장애물, 점프/숙이기 조작
   - 500점 단위 낮/밤 테마 전환
6. 💣 **지뢰 찾기 게임 (Minesweeper)**
   - 9×9 모바일 최적화 그리드 (10개 지뢰)
   - **조작**: 짧은 탭 = 타일 열기 / **길게 누르기(320ms 롱프레스)** = 깃발 🚩 꽂기/해제
   - 상단 실시간 남은 지뢰 카운터 및 타이머, 하단 **[🔄 재시작]** 버튼
   - 첫 탭 무조건 안전 타일 보장

## 📲 APK 다운로드 방법 (GitHub Actions 자동 빌드)

본 저장소의 `main` 브랜치에 코드가 푸시되면 **GitHub Actions CI/CD**가 자동으로 안드로이드 APK를 빌드합니다.

1. 본 GitHub 저장소 상단의 **[Actions]** 탭으로 이동합니다.
2. 가장 최근 실행된 **"Build Android APK"** 워크플로우를 클릭합니다.
3. 하단의 **Artifacts** 섹션에서 **`Arcade-Games-Debug-APK`** (또는 **Releases** 탭)를 다운로드합니다.
4. 압축을 푼 후 스마트폰에 `app-debug.apk`를 설치하여 플레이합니다.

## 💻 로컬 개발 및 브라우저 테스트

```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 프로덕션 웹 빌드 및 Capacitor 동기화
npm run build
npx cap sync android
```
